# Contributing Guidelines

Thank you for contributing to the Student Complaint Management System (SCMS)!

## Development Workflow

1. **Branching Strategy**
   - `main`: Production and stable release code.
   - `dev`: Active integration branch.
   - `feature/<feature-name>`: Create new features by branching off `dev`.

2. **Pull Requests**
   - Submit PRs targeting the `dev` branch.
   - Ensure all code builds and tests pass before submitting.
   - At least one code review is required before merging.

3. **Coding Standards**
   - Follow standard C# and .NET coding conventions.
   - Ensure meaningful commit messages and proper documentation.
